# Results status

The repository contains 165 main manifests (159 completed and 6 excluded after a harness defect), a separate 54-run duplicate-mechanism dataset in `e3dup/`, and an 8-run cross-peer dataset in `multinode/` (plus 8 additional pre-fix runs retained under `multinode_pre_fix_invalid/` and used for no claim). Retained artifacts include JSONL logs, manifests, source-distribution hashes, environment metadata, configurations, and run metadata. See `trials/README.md`, `e3dup/README.md` and `multinode/README.md` for the experiment inventory and scope.
